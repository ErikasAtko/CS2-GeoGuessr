# CS2-GeoGuessr

CS2-GeoGuessr is a GeoGuessr-style guessing game for Counter-Strike 2: you're shown a screenshot taken from somewhere on a CS2 map and have to click the spot on the map where you think it was taken - the closer the guess, the more points scored.

## End-to-End Scenario

Your NOOB friend just carried you, and you've got no comeback because your hands were cold. Fire up CS2-GeoGuessr and flex your map knowledge instead: a screenshot from somewhere on Dust II pops up next to the full map. You study the lighting and geometry, then click the spot where you think it was taken. The game reveals the real location and scores you on how close you got. Beat your friend to prove you're not completely cooked.

## Structure

```
CS2-GEO/
├── Data/Entities/       C# classes that EF maps to database tables (Map, Location)
├── Data/GameDbContext   the entry point for every database query
├── Dtos/                response shapes sent to the client
├── Endpoints/           HTTP route definitions grouped by feature (/api/maps, /api/rounds)
├── Game/                domain logic: Point, scoring, guess results
├── Migrations/          versioned schema changes; generated by EF, never edited by hand
├── wwwroot/images/      static assets served directly: location screenshots and minimaps
└── api.http             ready-made requests to exercise the API without running the frontend

frontend/
└── src/
    ├── components/      StartScreen, GameScreen, MinimapGuesser, ResultScreen
    ├── api.ts           typed fetch calls to the backend
    ├── types.ts          TS shapes matching the backend DTOs
    └── App.tsx           screen state machine driving the start -> play -> result loop

database/seed1.sql       seed data: the maps and locations the game starts with
```

## Build and Run

You need both the backend and the frontend running at the same time - they're separate processes on separate ports and talk to each other over HTTP (CORS is already configured on the backend to allow this).

### Backend (ASP.NET Core, `CS2-GEO/`)

1. Set up `CS2-GEO/appsettings.Local.json` with your own DB connection string (see [Databases](#databases) below) - copy `appsettings.Local.example.json` and fill in your credentials.
2. From `CS2-GEO/`:
   ```
   dotnet restore
   dotnet ef database update
   dotnet run
   ```
3. The API starts on `http://localhost:5080` (see `Properties/launchSettings.json`).

### Frontend (React + Vite, `frontend/`)

Requires [Node.js](https://nodejs.org/) (LTS) installed - this gets you `npm`.

From `frontend/`:
```
npm install
npm run dev
```

The dev server starts on `http://localhost:5173` and expects the backend to already be running on `http://localhost:5080`. Open `http://localhost:5173` in your browser to play.
