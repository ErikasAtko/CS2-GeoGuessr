# CS2-GeoGuessr

A GeoGuessr-style guessing game built around Counter-Strike 2. Players are shown a screenshot taken from somewhere on a CS2 map and have to click the spot on the map where they think it was taken - the closer the guess, the more points scored.

## Goals

- Alpha: a working singleplayer guessing loop - see an image, guess on the map, get scored on distance.
- Beta: play with friends via multiplayer lobbies.
- Final: multiple maps, player profiles/statistics, accounts, and possibly ranking and difficulty settings.
